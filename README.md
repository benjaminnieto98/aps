# APS – Asociación de PES6

## Instalación

```bash
# Backend
cd server
npm install

# Frontend
cd ../client
npm install
```

## Seed (primera vez)
```bash
cd server
npm run seed
```

## Desarrollo
```bash
# Terminal 1 – Backend
cd server
npm run dev

# Terminal 2 – Frontend
cd client
npm run dev
```

Backend: http://localhost:3001
Frontend: http://localhost:5173

## Credenciales de admin
- Código admin por defecto: `aps2006`
- Al registrarte, ingresa el código en el campo opcional para obtener acceso admin.

## Funciones principales
- Mercado de jugadores con precio de venta y cláusulas de rescisión
- Sistema de presupuesto por manager
- Torneos (todos vs todos o grupos) con generación automática de fixture
- Tabla de posiciones y goleadores en tiempo real
- Panel de administración completo
